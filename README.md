### 🏙️ CetiNET

**Founder & Sole Developer**

CetiNET is a smart-city mobile platform developed through the **Youth4Smart Cetinje** initiative.

The platform connects mobile software with live IoT infrastructure and provides real-time urban and environmental data.

Key technologies and systems include:

- Flutter / Dart
- REST APIs
- IoT sensor networks
- LoRaWAN
- Real-time data
- Smart-city infrastructure
- Municipal monitoring

The Youth4Smart Cetinje initiative was recognized as a **WSIS Champion Project in the E-Environment category by the International Telecommunication Union (ITU)**.
